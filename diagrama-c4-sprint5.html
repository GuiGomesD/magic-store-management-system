Escopo e convenções

As visões C4 mostram a arquitetura em níveis progressivos de abstração: pessoas e sistema, contêineres executáveis e componentes do backend. O UML é uma visão complementar — não um nível do C4 — e detalha classes, interfaces, atributos, operações e relações confirmadas no código.

Relacionamentos dos componentes

Fluxo HTTP: Routers → Schemas para validar DTOs; Routers → FacadeSingletonController para executar casos de uso. Orquestração: Fachada → Commands → GerenciadorProdutos; Fachada → GerenciadorUsuarios; Fachada → Relatórios. Persistência: Fachada → Fábricas → Repositórios; gerenciadores e relatórios → contratos de repositório. Colaborações: GerenciadorProdutos → Memento/Observer/Strategy; infraestrutura de logging → Python logging.
